# Starter Vault

这里保存可公开维护的脱敏模板、Canvas、Bases、Agent Definitions 和最小 Obsidian 配置。

为避免重复维护构建产物，本目录不提交 `.obsidian/plugins/ai-knowledge-os`。安装时先复制本目录内容到目标 Vault，再把仓库根目录中的 `manifest.json`、`main.js`、`styles.css`、`README.md` 和 `DEFUDDLE-LICENSE.txt` 复制到：

```text
目标 Vault/.obsidian/plugins/ai-knowledge-os/
```

已发布的完整体验包可从 GitHub Releases 下载。
