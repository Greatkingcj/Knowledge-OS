# AI Agent

AI Agent 是能够理解目标、使用工具、读取上下文并通过多步行动完成任务的系统。

## 设计要素

- **目标**：结果必须可检查。
- **上下文**：知道当前项目、资料范围与权限。
- **工具**：能搜索、写入、执行和验证。
- **记忆**：把关键状态留在知识库，而不是只留在聊天记录。
- **护栏**：明确不可做事项、审批点与失败处理。
