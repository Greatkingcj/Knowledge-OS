# 知识库

知识库不是文件仓库，而是能被人和 Agent 稳定检索、理解、引用和维护的事实系统。

## 最小质量标准

- 来源清楚，知道谁在什么时间说了什么。
- 结论与原始资料分层，避免二次加工冒充原文。
- 链接有原因，不用同文件夹代替真实关系。
- 重要内容有状态、更新时间和责任边界。
- 检索结果可验证，AI 输出能够回到具体证据。
