# AI Knowledge OS · 开始使用

这是一个经过脱敏的 AI Knowledge OS 演示 Vault，包含插件、模板、Base、Canvas 和通用示例知识。

## 第一次打开

1. 在 Obsidian 中选择“打开本地文件夹作为仓库”。
2. 选择解压后的 `AI Knowledge OS Starter Vault` 文件夹。
3. 如果 Obsidian 提示第三方插件安全确认，请确认信任本地安装的 `AI Knowledge OS`。
4. 确认核心插件 Graph、Canvas、Bases 和 File Explorer 已启用。
5. 点击左侧 Ribbon 中的紫色大脑图标。

也可以打开命令面板，执行：

```text
AI Knowledge OS：打开知识驾驶舱
```

## 建议体验顺序

1. Dashboard：查看整个 Vault 的动态统计。
2. Inbox：创建快速记录或采集网页。
3. Knowledge：浏览示例概念与原生关系图谱。
4. Graph：查看主题关系页面。
5. Projects：打开示例项目并勾选任务。
6. Analytics：查看知识增长和结构分析。

## 修改用户名称

打开 Obsidian 设置 → AI Knowledge OS → 显示名称。

## Claudian

本体验包没有附带 Claudian，也不包含任何 API Key 或登录信息。如需 AI 深度处理，请自行安装和配置 Claudian。

## 重要说明

- 当前 Agent“立即运行”只会创建任务模板，不会自动调用模型。
- 部分标为 AI 的功能使用本地规则和统计公式。
- Graph 主页面包含预设主题结构；Knowledge 页面底部嵌入的 Obsidian Graph 才是原生关系图谱。
- 所有新增内容均保存在当前本地 Vault。
